# Product Vision

## Project

**Aurora Overlay Framework**

---

# Mission

Aurora Overlay Framework makes professional stream overlays accessible to everyone.

Instead of manually editing HTML, CSS and JavaScript, streamers can create, customize and manage overlays through an intuitive visual interface.

Aurora focuses on simplicity for creators while remaining powerful enough for developers to extend through themes, widgets and plugins.

---

# The Problem

Creating overlays for OBS and Mix It Up often requires knowledge of HTML, CSS and JavaScript.

Many streamers:

- don't know how to code;
- struggle to customize existing overlays;
- rely on outdated or paid overlay packs;
- spend more time editing code than creating content.

Aurora removes this barrier by replacing code with a visual configuration experience.

---

# The Solution

Aurora provides a visual overlay designer that allows users to:

- create overlays using reusable widgets;
- customize colors, fonts and layouts visually;
- preview overlays in real time;
- save complete overlay projects;
- export overlays ready for use in Mix It Up and OBS.

No programming knowledge should be required for common use cases.

---

# Target Audience

### Primary

- Twitch streamers
- YouTube streamers
- Kick streamers
- Beginning content creators

### Secondary

- Overlay designers
- Developers creating custom widgets
- Open-source contributors

---

# Core Principles

Aurora should always be:

- Easy to use
- Visual first
- Modular
- Extensible
- Fast
- Open Source
- Community driven

---

# Version 1.0 Goals

Aurora 1.0 should allow users to:

- Create overlays visually.
- Configure widgets without code.
- Preview overlays live.
- Save projects.
- Export overlays for Mix It Up.
- Export Browser Sources for OBS.
- Import previously created Aurora projects.
- Apply themes with one click.

---

# Future Goals

Possible future features include:

- Drag & Drop editor
- Plugin marketplace
- Online theme library
- Community widget library
- Cloud synchronization
- Automatic updates
- Team collaboration
- Mobile preview
- AI-assisted widget generation

---

# Non-Goals

Version 1.0 will NOT include:

- Video editing
- Streaming software
- Chat bot replacement
- Scene switching
- OBS replacement
- Mix It Up replacement

Aurora complements existing streaming software instead of replacing it.

---

# Success Criteria

Aurora succeeds when a streamer with no programming experience can:

1. Create an overlay.
2. Configure widgets.
3. Preview the result.
4. Export everything.
5. Use it immediately inside OBS and Mix It Up.

without writing a single line of code.

---

# Long-Term Vision

Aurora aims to become the open-source standard for creating configurable streaming overlays.

Developers should be able to build reusable widgets, themes and plugins, while streamers can focus entirely on designing beautiful overlays through an intuitive interface.
