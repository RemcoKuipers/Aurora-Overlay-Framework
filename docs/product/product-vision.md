# Product Vision

## Project

**Aurora Overlay Framework**

---

# Mission

Aurora empowers streamers to create professional overlays through an intuitive visual workspace, eliminating technical barriers so they can focus on creating content instead of configuring software.

---

# Vision

To become the leading open-source platform for designing, managing and sharing streaming overlays.

Aurora is built **by streamers, for streamers**.

---

# The Problem

Modern streaming setups require users to combine multiple applications and technologies.

Creating overlays often means learning:

- OBS Studio
- Mix It Up
- HTML
- CSS
- JavaScript
- Browser Sources
- Scene management

Many streamers spend hours watching tutorials before creating their first working overlay.

Aurora exists to remove these technical barriers.

---

# The Solution

Aurora provides a visual workspace where streamers can design complete overlay projects without programming knowledge.

Instead of writing code, users create overlays by:

- Creating a project
- Creating scenes
- Adding widgets
- Customizing themes
- Previewing changes live
- Exporting directly for Mix It Up and OBS

Aurora generates the required HTML, CSS and JavaScript automatically.

# Design Principles

Aurora follows these principles:

- Everything is a Project
- Users think in Scenes, not files
- Widgets should be reusable
- Simplicity over complexity
- Export should be effortless

---

# Version 1.0 Goals

Aurora 1.0 allows users to:

- Create projects
- Create multiple scenes
- Configure widgets visually
- Preview overlays in real time
- Save Aurora projects
- Import Aurora projects
- Export overlays for Mix It Up
- Export Browser Sources for OBS
- Apply themes with one click

No programming knowledge should be required.

---

# Non-Goals

Aurora will not replace:

- OBS Studio
- Mix It Up
- Streaming software
- Video editors
- Chat bots

Aurora complements existing streaming tools.

---

# Success Criteria

Aurora succeeds when a new streamer can:

1. Create a project.
2. Build multiple scenes.
3. Configure widgets visually.
4. Export everything.
5. Start streaming.

...without writing HTML, CSS or JavaScript.

---

# Long-Term Vision

Aurora aims to become the standard open-source ecosystem for stream overlays.

Developers create widgets.

Designers create themes.

Streamers create content.

Aurora connects them all.
