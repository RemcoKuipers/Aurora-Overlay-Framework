# User Personas

Aurora is designed for multiple types of users.

Understanding their goals and frustrations helps guide product and architectural decisions.

---

# Persona 0 — Community Streamer

## Experience

Uses Mix It Up daily.

## Goals

- Build overlays without coding.
- Spend time interacting with chat.
- Customize everything visually.
- Share overlay templates with others.

## Aurora should help by

- Making every action visual.
- Requiring little to no technical knowledge.
- Providing community templates.
- Making customization simple.

# Persona 1 — New Streamer

## Name

Emma

## Experience

Beginner

## Goals

- Start streaming as quickly as possible.
- Create professional-looking overlays.
- Avoid learning HTML, CSS and JavaScript.
- Spend more time creating content.

## Frustrations

- OBS feels overwhelming.
- Mix It Up requires many tutorials.
- Existing overlays are difficult to customize.
- Everything feels disconnected.

## Aurora should help by

- Providing project templates.
- Offering a visual editor.
- Generating overlays automatically.
- Keeping the workflow simple.

---

# Persona 2 — Experienced Streamer

## Name

Mark

## Experience

Intermediate / Advanced

## Goals

- Build overlays faster.
- Reuse widgets.
- Maintain a consistent style.
- Quickly update existing projects.

## Frustrations

- Editing multiple overlay files.
- Managing HTML, CSS and JavaScript separately.
- Repeating the same work.

## Aurora should help by

- Supporting reusable widgets.
- Supporting themes.
- Allowing project exports.
- Managing complete streaming projects.

---

# Persona 3 — Overlay Designer

## Name

Lisa

## Experience

Creative Designer

## Goals

- Create beautiful themes.
- Share themes with the community.
- Design visually.

## Frustrations

- Depending on developers.
- Difficult customization.
- Poor portability.

## Aurora should help by

- Providing a theme system.
- Supporting theme exports.
- Making themes reusable.

---

# Persona 4 — Developer

## Name

Remco

## Experience

Developer

## Goals

- Extend Aurora.
- Build custom widgets.
- Create plugins.
- Improve the framework.

## Frustrations

- Tight coupling.
- Poor documentation.
- Difficult architecture.

## Aurora should help by

- Providing a modular architecture.
- Offering clear documentation.
- Supporting plugins.
- Encouraging open-source contributions.

---

# Shared User Goals

Regardless of experience, every Aurora user wants to:

- Spend less time configuring software.
- Spend more time streaming.
- Create beautiful overlays.
- Reuse existing work.
- Share projects with others.

---

# Product Promise

Aurora exists to help creators focus on creating content—not configuring software.

Every feature should contribute to that promise.
